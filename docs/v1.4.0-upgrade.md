# Upgrading to Hammerspace CSI v1.4.0

## Compatibility

| Component | v1.4.0 policy |
| --- | --- |
| Kubernetes | 1.30 through 1.36; the bundled manifest targets 1.36 |
| CSI | Spec 1.13 |
| Filesystems | NFS, ext4, XFS, and raw block |
| Packaging | Raw Kubernetes 1.36 manifest or Helm 3 |

Existing v1.3 volumes retain their volume handles and remain mountable. Upgrade
the controller first, then roll the node DaemonSet. Do not run v1.3 and v1.4
controllers concurrently because only v1.4 participates in the driver's Lease.

## Required preparation

TLS verification is now enabled by default. Install the Anvil CA and configure
`HS_CA_BUNDLE` before upgrading if the management endpoint uses a private CA.
`HS_TLS_VERIFY=false` remains a temporary compatibility escape hatch and emits a
warning. See `deploy/kubernetes/SECRETS.md`.

The controller now has two replicas and requires Lease and the two scoped
ConfigMaps in the v1.36 manifest. Snapshot freeze recovery and file-snapshot
idempotency depend on those ConfigMaps.

`CSIDriver.attachRequired` is now false and the external attacher is removed.
No VolumeAttachment is required because Hammerspace volumes are mounted directly
by the node service.

## Upgrade

1. Back up the credential Secret and StorageClass definitions.
2. Install the CA Secret/ConfigMap where required.
3. Apply `deploy/kubernetes/kubernetes-1.36/plugin.yaml`, or run
   `helm upgrade --install` with the v1.4 chart.
4. Wait for one controller to acquire `hammerspace-csi-controller` and for both
   controller pods to become Ready.
5. Confirm all node pods have registered `com.hammerspace.csi`.
6. Verify an existing PVC, then create, snapshot, clone, and expand a canary PVC.

## Rollback

Scale the v1.4 controller to zero before restoring v1.3. Existing volumes remain
compatible. Do not delete the v1.4 state ConfigMaps until every frozen-target
record has been reconciled. v1.3 does not understand the v1.4 leader Lease, so
never overlap the two controller versions.

Rollback qualification must verify existing mounted PVCs, a newly provisioned
PVC, and snapshot deletion. TLS settings may need to be restored explicitly.
